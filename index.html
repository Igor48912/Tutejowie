OsobaDatyRodzice

Zdjęcia trzymasz w folderze na Dysku Google, a strona pokazuje je z listy zapisanej w pliku dane.js (odwiedzający nie łączą się z Dyskiem, tylko pobierają miniatury). Po zmianach kliknij „Eksportuj dane” i wgraj dane.js na hosting.

Jak połączyć folder z Dysku Google?
  1. Udostępnij folder: w Dysku kliknij folder prawym przyciskiem → Udostępnij → „Dostęp ogólny” → Każda osoba mająca link, rola Przeglądający. Bez tego zdjęcia nie wyświetlą się odwiedzającym.
  2. Klucz API (jednorazowo): wejdź na console.cloud.google.com → utwórz projekt → „Interfejsy API i usługi” → włącz Google Drive API → „Dane logowania” → „Utwórz dane logowania” → Klucz API. Skopiuj go do pola powyżej.
  3. Kliknij Synchronizuj z folderem. Podfoldery stają się albumami, a rok jest brany z nazwy pliku lub folderu (np. „1939 wrzesień”) albo z daty zdjęcia. Opis pliku na Dysku zostanie podpisem.
  4. Możesz poprawić tytuły, albumy i lata w tabeli poniżej – przy kolejnej synchronizacji Twoje poprawki zostaną zachowane.
  5. Bez klucza: użyj „+ Dodaj zdjęcie ręcznie” i wklej link do zdjęcia („Udostępnij → Kopiuj link”).
